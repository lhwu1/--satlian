# 沿线高质感素材生成 Skill

## 能力边界

本 Skill 只生成独立 HTML 素材和素材元数据，不修改已有素材、不写入外部网络、不实现射击伤害或地图运行逻辑。需要改已有素材时，先用 `list_assets` 找到源素材，再通过 `sourceAssetId` 或 `cloneOf` 创建新的 `ai.` ID；原文件永远保留。

支持四类素材：武器、人物、道具/建筑、材质。每个素材必须使用米制局部坐标、中文名称、`alongSlots`、局部 AABB `alongColliders` 和本地 base64 `previewImage`。

## 工作流程

1. 调用 `read_guidance`，传入用户需求和参考图列表；参考图用于分析轮廓、比例、部件、材质、磨损和镜头。
2. 调用 `list_assets` 判断是否已有可复用素材。缺少时先生成素材，再组装地图。
3. 生成一个完整 HTML：真实几何、分件材质、碰撞、锚点和最终渲染预览都在文件内。
4. 生成前进行分类自检；生成后调用 `create_asset`。MCP 拒绝时根据错误重做，不能降低门槛绕过。
5. 用预览器检查亮度、比例、中文标题、材质层次和碰撞，再继续下一个类别。

## 质量标准

参考图是结构和比例约束，颜色只是推荐。不要把参考图颜色硬编码成唯一答案；应学习其真实分件、边缘倒角、磨损层次、材质粗糙度和光照关系。预览必须是最终真实渲染，主体清晰，占画面主要区域；黑屏、单色方块、单球材质和占位插画都是反例。

- 武器必须拆出枪口/枪管、机匣、护木、弹匣或弹鼓、握把、枪托、瞄具、扳机护圈，至少 8 个独立 Mesh，并混合圆柱、挤压或曲线几何。
- 人物必须有头部/头盔、躯干/战术背心、双臂/双手、双腿/鞋靴和装备层，至少 8 个独立 Mesh；手与武器握把位置要匹配。
- 道具/建筑必须有主体、结构支撑、连接件或开口，至少 3 个可见部件；门窗洞口要是真空缺。
- 材质必须在球、方块、斜面或平面等至少三种形状上展示颜色、粗糙度、金属度或纹理。

## 反例与修复

- 黑背景下几个方盒拼成枪：补齐部件、倒角和材质槽，增加真实预览后重新提交。
- 只有一个球的材质：加入带厚度方块和斜面，并调整粗糙度/金属度让光照产生差异。
- 胶囊人或无装备人物：按人体部件拆分并加入战术背心、手套、护具和鞋靴。
- 只用贴图画门窗的建筑：改为真实开口和分段碰撞。
- 远程缩略图或黑屏预览：从最终渲染导出本地 base64 PNG/JPEG/WebP。

## 输出要求

所有名称、材质槽名称和预览标题使用中文；ID 使用唯一小写 `ai.` 前缀。完成后报告素材路径、分类、自检结果和 MCP 验收结果。地图生成仍需满足晴天、底板、双方出生点和四面空气墙规则。
