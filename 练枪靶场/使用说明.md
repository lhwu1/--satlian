# 鼠标校准与训练

双击 `沿线练枪靶场.exe` 打开 Tauri 桌面窗口，无需 BAT 或单独安装 Python。程序自动启动本机服务（127.0.0.1:8876）；关闭桌面窗口时，服务会随之退出。固定端口用于保留训练记录和 DPI 设置，如端口被占用请先关闭占用程序。不要打开工作区上级目录中的原始 `index.html`。Windows 需要 Microsoft Edge WebView2 运行时。

入场时屏幕中央的 P 键提示会闪动并在 3 秒内淡出。右上角问号或 Tab 可以展开、收起操作帮助。固定靶只在本批剩余 3 个及以下时显示小型字母与距离标识。

DPI 滑条与输入框双向联动。校准或手填驱动值确立硬件基准后，滑条调整页面等效 DPI：例如基准 800、页面 1600 时，视角输入为 2 倍；页面 400 时为一半。页面灵敏度是额外倍率。AI 优化时，页面 DPI 滑条会平滑移动并显示前后数值，硬件基准记录保持不变。该功能不修改鼠标固件，也不修改 Windows 桌面指针速度。

- 开始训练前，填写鼠标驱动中显示的硬件 DPI，或使用实际距离校准。基准和页面 DPI 会保存在当前浏览器，切换硬件 DPI 档位后需重新校准或在“校准 / 确认 DPI”中填写新的驱动值。
- 校准默认移动 1 英寸（2.54 cm）。先在桌面用尺子量好两端，点击校准并授权，鼠标放在左端后按空格开始，水平移到实际右端后按 Enter 完成。允许用更长的实测距离减小测量误差；建议重复测量核对结果。
- 授权后，Windows 本机后台通过 Raw Input 采集相对移动计数。DPI = 水平净计数 ÷ 实际英寸。计数不按画面帧数采样，也不经过 Windows 指针速度换算。采集完成、取消、页面关闭或最长 30 秒后停止，不保存原始记录，不将原始校准记录上传 AI。后台必须和浏览器位于同一台电脑。触控板或使用绝对坐标的设备不保证可用。
- 屏幕引导条自适应窗口宽度，按已知基准（未知时暂按 800）显示参考进度；引导到右端不代表实际移动已满 1 英寸。显示器分辨率、缩放和帧率无法确定桌面物理距离，所以屏幕条不作为第二个物理测量值参与平均。浏览器估算作为明确标注的兼容选项，其普通输入可能受系统指针速度和加速影响。
- “授权读取本机鼠标设置”会先弹出授权提示。同意后，后台只读取 Windows 指针速度和加速度，不修改系统设置，也不把这些设置上传给 AI。未授权时不会读取。
- Windows 通用接口无法查询所有鼠标的硬件 DPI，因此未实现厂商驱动适配时显示“未知”。本机后台只能读取后台所在电脑的设置。若要直接读取特定鼠标 DPI，需要该型号的厂商 SDK 或协议支持。
- 完成倒计时后生成靶子。每轮结束显示评分、命中率、平均命中间隔和改进建议。命中间隔包含寻找靶子和移动时间，不等于严格反应时。
- AI 只在结算时由用户点击执行，分析本轮射击和聚合鼠标轨迹。每次调整页面 DPI 的幅度限制在 ±10%，视角速度同步变化，展示原因后询问是否再来一局。AI 不修改硬件 DPI；分析失败时保留当前设置。保持相同硬件 DPI 和靶型，比较多轮结果才能判断是否更适合自己。
