    训练前 · 鼠标校准

    在桌面上用尺子量出 1 英寸（2.54 cm）。授权后先将鼠标放在左端，按空格开始采集，水平移到右端后按 Enter。实际距离可自行改大，以减小测量误差。

    尚未读取系统设置。此功能需要本机后台运行。

    DPI = 水平原始计数 ÷ 实际移动英寸。屏幕条会适配窗口大小，仅作引导；它不等同于桌面物理距离，也不参与帧率换算。

    允许本次原始鼠标校准？

    按空格开始后，本机后台将通过 Windows Raw Input 采集鼠标相对移动计数，不受系统指针速度或画面帧数换算影响。只在本轮校准期间采集，完成、取消或 30 秒后停止。

    原始计数仅用于本机距离估算，不保存原始记录、不上传给 AI，不修改系统或硬件 DPI。请只移动用于练枪的一只鼠标。

    允许读取本机鼠标设置？

    本机后台将读取 Windows 指针速度和加速度设置，用于提示校准误差，不会修改系统设置。硬件 DPI 通常无法通过 Windows 通用接口获取；读取的设置不上传给 AI。

    只适用于后台与浏览器在同一台电脑上运行。远程后台无法读取你这台电脑的鼠标。
