# 沿线：素材与地图编辑器方案

用户提供一个素材 HTML，未来的地图编辑器应能预览素材、拖入场景、调位置/旋转/大小、编辑碰撞与空气墙、配置出生点和天气，最后将地图导出为可切换的独立 HTML。对战玩法与地图文件分开；每张地图单独保存，切换地图就是切换地图 HTML。

**当前已完成的是原场景素材拆分与预览，不是地图编辑器。** 自动扫描、目录拖拽、材质替换、碰撞编辑、空气墙编辑、地图保存和自包含导出均未实现，后续实现时需按本文协议设计并逐项验证。

原场景清单在 `素材/公共/原场景清单.json`。该文件列出 36 个原始道具、48 个命名材质、57 类合成声音。另有 13 个场景/背景/地面/角色/武器入口，以及 HUD 和特效资源。不是只有六项；旧的六个 `素材/原有场景/原有*.html` 是便于理解的精选入口，与完整分类目录并存。源码分段和校验资料在 `素材/公共/`。

原始 `index.html` 与 `练枪靶场/saltline-original.html` 只作为来源，保持原样。`素材/暖阳旧木-课桌.html` 是用户已有文件，也保持原样。

## HTML 素材接口

每份素材 HTML 包含 `#along-asset` 元数据 JSON 和 `#along-factory` 工厂函数体。schema 固定为 `along.html-asset/1`。工厂使用注入的 `ctx.THREE`，可选调用 `ctx.original` 中的原始构造器，返回独立 `THREE.Object3D`。尺寸单位为米，Y 向上，坐标和碰撞均为素材局部坐标。碰撞通过 `object.userData.alongColliders` 表示局部 AABB；可换材质通过 `alongSlots` 和网格 `alongSlot` 表示。

新的 AI 素材规则和模板按类别放在 `docs/ai素材指南/`，总入口为 [AI素材生成指导](AI素材生成指导.md)。新素材应保存到 `素材/AI生成/`，名称不可覆盖已有文件。原有素材由共享运行时预览，单独复制时还需 `素材/公共/`；未来地图导出器负责将依赖打包进地图文件。

## 推荐编辑器实现顺序

1. 扫描素材目录或允许用户手动选择 HTML；解析 JSON、检查重复 ID、显示名称/类别/错误，不静默覆盖。
2. 在隔离预览环境读取素材工厂；工厂返回对象后，将模型本身放入编辑场景，不把预览 iframe 当作模型。
3. 提供拖放、变换、复制、删除、撤销/重做和局部碰撞可视化。空气墙应作为独立地图对象编辑，不能藏进美术模型。
4. 保存地图对象的素材 ID、变换、材质配置、碰撞/空气墙、出生点和环境设置。地图按单独 HTML 保存。
5. 导出时内嵌所需运行时代码、几何、材质和依赖数据，断网并移出素材目录后仍能打开。导出失败须给出错误，不能生成残缺地图。
6. 先验证单素材加载、变换/碰撞一致、地图重开和离线导出，再实现对战加载与多人玩法。

未经审查的 HTML 含可执行代码。预览/导入应使用隔离环境；素材元数据校验不能代替代码安全隔离。禁止执行网络下载或访问用户本地凭据。

## 预览和验证边界

通过项目根目录的本地 HTTP 服务打开 `素材/原有场景/` 下分类 HTML，保证共享运行时同源。各素材目前由浏览器预览器调用并显示尺寸/错误状态；这不等同于编辑器拖拽测试、完整物理碰撞测试或离线地图导出测试。原始场景中的音频和外链若仍在共享运行时，应单独审查，不能据此扩展 AI 新素材的外链权限。
