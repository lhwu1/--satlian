# 沿线：HTML 素材与地图编辑器方案

用户将素材 HTML 放进素材目录，在地图编辑器中看到并拖入三维场景，调整位置、旋转和大小，绘制空气墙、设置出生点及天气，最后导出地图 HTML。未来对战等玩法由游戏加载所选地图 HTML；地图文件与其资源保存在地图目录，切换地图即选择另一份地图 HTML。素材可以复用、单独修改；原始 `index.html` 不修改。

**目前状态：编辑器、自动扫描、地图导出和对战加载器尚未实现。** 本次提供的原有素材 HTML 使用公共运行时独立预览，文件之间没有重复存储整套场景代码。它们是后续编辑器协议的首批素材，并非已经实现的拖拽编辑器。AI 使用的完整格式见 [AI 素材生成指导](AI素材生成指导.md)。

## 文件组织

```text
素材/
  公共/                  原场景共享运行时及预览器
  原有场景/              仓库、集装箱、箱子、油桶和标点，各一份 HTML
  AI生成/                用户放置 AI 输出的素材 HTML
地图/
  地图名称.html          编辑器导出的自包含地图
编辑器/                  未来实现的编辑器与本地素材索引服务
```

已有 `素材/暖阳旧木-课桌.html` 保持原样；它采用另一套外链与脚本结构，不符合新协议，不能自动变成可拖拽素材。需另做适配、确认本地依赖后才可使用。用户自己的文件不被自动覆盖。

## 素材 HTML 协议

每个 HTML 是一个素材入口，包含 `#along-asset` 元数据 JSON 和 `#along-factory` 工厂代码。工厂接收同一运行时的 `ctx.THREE` 和可选 `ctx.original`，返回独立 `THREE.Object3D`；网格、材质和子节点一起返回，局部原点用于定位，尺寸以米计。碰撞由 `object.userData.alongColliders` 提供局部 AABB 数组；编辑器将其随实例变换。新 AI 素材通过 `alongSlots` 和网格的 `alongSlot` 标明可替换材质；人物使用命名关节层级，武器提供枪口、握把、准星锚点。原有素材尚未全部标注这些可编辑槽位，不能当作已经支持换材质。细节、完整样例与限制见 AI 指导。

原有仓库与道具通过共享运行时调用原场景构建函数，不用简化盒子冒充原模型。公共运行时由 `素材/公共/生成原场景运行时.js` 从原始文件生成，仅修改副本、增加素材入口；原有素材入口由同目录的生成脚本生成。原有资产依赖公共运行时，因此单独拷贝一个 HTML 到别处时也需要公共目录；未来导出器负责将其依赖打包到地图 HTML。

仓库生成器复用原仓库构造代码，包含建筑和其构建器摆放的内部对象；原场景中由其他关卡步骤摆放的物件并不自动归属于该素材，需要另行拆分。标点素材是原场景继电器装置，不等同于游戏 UI 的 A/B/C 浮动指示。

## 编辑器及导出如何实现

1. 桌面端或本地服务扫描 `素材` 下符合协议的 HTML，解析元数据，展示名称、分类、缩略预览和加载错误。普通网页不能自行遍历本地目录；不依赖浏览器凭空读取文件夹。用户也可手动导入文件。不同路径的同 ID 提示冲突，不静默覆盖。
2. 编辑器启动一份共享运行时，读取素材工厂并在同一 Three.js 实例内创建对象，使用射线拾取和变换控件完成拖入、移动、旋转、缩放、复制、删除、撤销。贴合地面和网格吸附可选。实例保存素材 ID、来源与变换，不把整个 iframe 当作三维物体。
3. 编辑器提供独立空气墙工具：绘制、移动、缩放盒状体，编辑时可见，游戏中不可见但参与玩家碰撞；支持边界、门洞、出生点的可视化检查。素材自带碰撞与地图额外空气墙分开保存，缩放和旋转时同步转换。
4. 地图工程保存布局、素材源码或依赖快照、材质、天气、光照、碰撞、空气墙和出生点。地图运行时与编辑器共享同一解释器。导出时把需要的引擎、素材、程序化材质及本地资源内嵌到**一份** HTML；不得留下指向本机目录或 CDN 的必要依赖，重新打开可独立显示与运行。体积过大时应提供进度和明确失败提示，不静默导出残缺地图。
5. 未来游戏加载器读取所选地图 HTML 中约定的地图接口；玩法、玩家、AI、网络状态与地图数据分层。先定义地图入口、资源生命周期和碰撞接口并验证，再实现对战；不得声称现有靶场已支持切换。

生成的 HTML 内含代码，仅导入可信来源。桌面端需隔离预览、明确导入来源并限制文件和网络访问；校验元数据并不等于代码安全。不得把未受信任的素材直接放入拥有本机文件权限的游戏进程执行。

## 验收与实施顺序

1. 验证原场景各素材的几何、材质、局部原点和碰撞；对未能独立构建的部分记录限制，不伪装为完成。
2. 实现目录扫描、协议解析、冲突提示和单运行时素材预览。将 AI 输出的 HTML 放进 `素材/AI生成/`，刷新后能看到并加载；旧课桌另行适配。
3. 实现拖拽和变换、保存重开、碰撞和空气墙，再加入天气。用原有集装箱、仓库和 AI 素材一起组装地图，检查缩放后碰撞和出生点。
4. 导出单个 HTML，断网并移走素材目录后独立打开；确认画面、材质、布局、天气、空气墙与编辑器一致。最后才接入地图切换及对战。
