# 地图片段与碰撞生成指南

地图片段是可在编辑器中多次摆放的小型三维模块，不是完整游戏，也不是固定世界坐标的整张地图。阅读 [总规则与 HTML 模板](00-总规则与模板.md)，输出一个 HTML。

- 先写片段用途、宽深高、局部原点、连接方向和可进入区域。单位米、Y 向上，局部原点通常放在地面中心。
- 片段包含完整三维几何和默认材质。建筑要有墙厚和真实开口；平台、楼梯、走廊等要有可站立面。
- 碰撞盒全部用片段局部坐标。拆分墙盒、地板盒、栏杆盒，避免整块 AABB 挡住通道。每个碰撞说明表面类型。
- 可重复拼接的边缘需要尺寸一致，并明确入口/连接点坐标。推荐提供 `root.userData.alongAnchors`，值为命名的局部 `[x,y,z]`。
- 空气墙是地图编辑器里的独立编辑对象，不要在环境美术片段中暗藏不可见大盒子。只有用户明确要求边界片段时才输出可见或有文档说明的边界碰撞。
- 当前仓库、港口背景、船、吊机、小艇、地面天气和场景组合入口来自原场景。生成新片段时可参照其比例和配色，不能声称编辑器已支持拼装或导出。
