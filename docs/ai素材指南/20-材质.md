# 材质生成指南

阅读 [总规则与 HTML 模板](00-总规则与模板.md)，生成一个独立可预览的材质样板 HTML。

- 使用一个有厚度的球体、方块和/或平面展示同一材质在不同曲率和角度下的效果；样板要能看出粗糙度、金属度、颜色和图案。
- 将材质实现写在 HTML 工厂内，使用 `MeshStandardMaterial` 或适合的内置材质。图案可用内存 Canvas 程序绘制，并将 CanvasTexture 绑定到材质；不加载图片。
- 元数据 `category` 为“材质”，`assetKind` 为 `material`。提供稳定的槽位 ID 和中文槽位说明。
- 材质本身没有实体碰撞，`alongColliders=[]`。若预览样板有几何，它只是展示物，不应被当作游戏碰撞物。
- 说明适合的对象、颜色变化范围、粗糙度/金属度值，以及图案平铺方向。不要编造真实 PBR 图片贴图。

原场景目前有 48 个命名材质，例如混凝土、沥青、镀锌钢、锈钢、木材、橡胶、玻璃、船体漆和深色水面。新材质 ID 不得与之冲突。

## 预览与质量硬门槛

材质样板必须同时放置至少三种不同形状（例如球体、带厚度方块、斜面或平面），让光照能显示粗糙度、金属度和纹理差异。不要只放一个球；预览必须来自最终渲染并写入本地 base64 `previewImage`，不得用黑底占位图或远程图片。
