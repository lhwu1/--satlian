## 给小模型的最短指令

请先阅读 `docs/ai素材指南/AI素材生成指导.md` 和对应类别指南。视觉风格默认使用写实风格，并参考沿线现有港区素材；如果用户明确指定其他风格，则严格按指定风格生成。每个素材都要填写 `visualStyle` 和 `styleReference`，同一地图/套装里的新旧素材必须风格一致，禁止写实场景搭配玩具感角色或道具。严格按总规则生成**一个可离线使用的 HTML 文件**，包含完整几何/绘制内容、内嵌材质、局部碰撞和规定的 `along-asset` / `along-factory` 数据块。禁止外链、CDN、远程字体、图片、模型、音频和额外文件。先按模板生成，再逐项检查清单。不要声称未实现或未测试的功能已经可用。

## 当前素材范围

从原场景拆出的清单见 `素材/公共/原场景清单.json`：36 个道具、48 个命名材质、57 类程序合成声音；另有仓库/集装箱等场景组合、港口背景、地面天气、PAC-9 武器、第一人称双手、无人机和机械犬，以及 UI、特效演示资源。素材目录页和分类入口列出实际文件。原项目没有完整玩家人体模型，也没有录制的人声文件；第一人称手部、机械角色和合成音效不能描述成完整人体或真实语音。

原始 `index.html` 与 `练枪靶场/saltline-original.html` 是只读来源。生成素材只写入新素材文件。现已提供空白地图编辑器、对象材质、真实缩略图、MCP 生成和自包含地图观察页导出，操作与限制见 docs/设计方案/地图编辑器使用说明.md。人物与枪械尚未接入完整 FPS 对战。
