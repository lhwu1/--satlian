# 素材工厂模式：先装配，再细化

AI 生成武器时最容易犯的错误，是把参考图拆成一堆独立几何体，然后凭感觉填写 `position`。这样会出现枪管穿插、护木悬空、枪托断开、弹匣漂浮等问题。高质量原始 `weapon.html` 的关键是调用一个完整的武器工厂：所有零件共享同一套局部坐标、连接点、材质和手部锚点，细节是在连续灰模通过检查之后才加入的。

## 生成顺序

1. **提取轮廓**：先从参考图标出枪口、机匣前后端、护木前后端、弹匣安装面、握把安装面、枪托尾端和瞄具安装面。
2. **建立装配表**：只允许用装配表里的连接点计算位置，禁止每个零件单独猜坐标。
3. **生成连续灰模**：先做机匣、护木、枪管、弹匣、握把、枪托六个主体，验证相邻面接触和整体轮廓。
4. **添加功能件**：节套、导气系统、扳机护圈、导轨、准星、瞄具必须挂在对应主体上。
5. **添加材质和细节**：铆钉、散热槽、橡胶片和金属色差最后加入。面数和噪声不能掩盖断裂结构。
6. **真实预览验收**：提交前必须打开真实渲染预览，至少检查侧视、俯视和 45° 视角；缩略图必须由该渲染生成。

## 统一坐标与装配约束

武器局部坐标固定为：枪口方向 `-Z`，枪托方向 `+Z`，`Y` 向上，机匣中心为原点。所有长度单位为米。装配数据必须先写成下面的形式：

```js
const assembly = {
  receiver:  { front:-0.14, rear:0.17, centerY:0.015, size:[0.072,0.092] },
  handguard: { front:-0.14, rear:-0.40, centerY:0.018, size:[0.078,0.090] },
  barrel:    { chamber:-0.14, muzzle:-0.78, y:0.045, radius:0.014 },
  magazine:  { mount:[0,-0.03,0.02], center:[0,-0.075,-0.005], radius:0.075 },
  grip:      { mount:[0,-0.048,0.075], center:[0,-0.115,0.09] },
  stock:     { mount:[0,0.025,0.17], end:0.525 },
  sight:     { mount:[0,0.083,0.02], y:0.128 }
};
```

工厂函数应由这些连接点计算中心和长度：`center=(start+end)/2`，`length=distance(start,end)`。圆柱沿两点方向旋转，不能通过“先旋转再猜平移”修正轴向。相邻主体必须接触或重叠 1–3 mm；超过 5 mm 的空隙即判定装配失败。每个零件都要有中文 `name`、中文 `alongSlot` 和对应材质槽。

## 推荐工厂接口

```js
function box(name,size,slot,pos,rotation=[0,0,0]) { /* 创建并注册 Mesh */ }
function cylinderBetween(name,start,end,radius,slot) { /* 由端点计算长度与旋转 */ }
function mount(child,parent,offset=[0,0,0]) { /* 只允许相对父部件安装 */ }
function assertAssembly(spec) {
  // 检查连续性、比例、枪口/枪托方向、锚点和碰撞盒
}
```

禁止把整把枪用一个巨大碰撞盒包住，也禁止把部件直接挂到世界坐标后再用缩放掩盖错误。`root.userData.alongAnchors` 至少包含 `muzzle`、`grip`、`sight` 和 `stock`；`alongColliders` 必须按主体分别填写。

## 材质与细节规则

优先使用运行时已注册材质，例如 `gunmetal`、`steel_dark`、`anodized_black`、`polymer_black`、`rubber` 和 `brass`。金属主体应有连续的明暗层次，聚合物护木和握把应与机匣区分粗糙度；顶点噪声、划痕和铆钉只作为二级细节。不得用纯黑材质、发光镜片或随机颜色替代结构细节。

## 提交前质量闸门

- 真实渲染中主体轮廓连续，枪管、护木、机匣、弹匣、握把和枪托没有漂浮或断裂。
- 枪口在 `-Z`、枪托在 `+Z`，锚点与可视部件重合。
- 侧视图比例接近参考图，主体占预览画面的 70% 以上。
- 至少 8 个可识别中文部件，且每个都有材质槽和阴影。
- 预览图来自真实渲染，不得使用占位球、假缩略图或截图占位。
- 只复制已有素材生成新 ID；不得修改原始 `weapon.html` 或其他已有素材。

MCP 应在生成后依次执行：结构检查 → 装配连续性检查 → 材质槽检查 → 碰撞检查 → 真实预览检查。任何一项失败都要返回具体部件和坐标，模型先修正装配表再重新生成，不能只增加面数或随机细节。
