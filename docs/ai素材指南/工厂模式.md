# 素材工厂模式（必须遵守）

AI 不再从零随意拼接网格，而是按“部件清单 → 局部装配坐标 → 工厂函数 → 验收预览”生成。工厂函数只负责创建一个局部 `THREE.Group`，每个部件通过同一组 helper 创建、命名、挂槽位并加入根节点；这样可以保持比例、方向、材质和碰撞一致。

## 先写装配清单

生成前先列出部件表：部件中文名、中心坐标、尺寸、方向、材质槽、碰撞用途。武器的局部坐标统一为枪口 `-Z`、Y 向上、原点在机匣中心。参考图中的部件必须在表中逐项出现，颜色只作为推荐值。

## 通用工厂骨架

```javascript
const T=ctx.THREE, root=new T.Group();
const parts=[];
const mat={metal:ctx.original.material('gunmetal'), polymer:ctx.original.material('steel_dark'), rubber:ctx.original.material('rubber')};
function part(name,geometry,material,position,slot,rotation=[0,0,0]){
  const mesh=new T.Mesh(geometry,material); mesh.name=name; mesh.position.set(...position); mesh.rotation.set(...rotation);
  mesh.userData.alongSlot=slot; mesh.castShadow=true; mesh.receiveShadow=true; root.add(mesh); parts.push(mesh); return mesh;
}
function box(name,size,position,material,slot,rotation=[0,0,0]){return part(name,new T.BoxGeometry(...size,2,2,2),material,position,slot,rotation);}
function tube(name,radius,length,position,material,slot){const g=new T.CylinderGeometry(radius,radius,length,24);g.rotateX(Math.PI/2);return part(name,g,material,position,slot);}
// 按装配清单调用 box/tube/extrude 等 helper；大部件优先 Shape+ExtrudeGeometry(bevelEnabled:true)
root.userData.alongSlots=parts.map(p=>({id:p.userData.alongSlot,name:p.name}));
root.userData.alongAnchors={muzzle:[0,0.04,-0.78],grip:[0,-0.05,0.08],sight:[0,0.07,0.01]};
root.userData.alongColliders=[/* 按部件填写局部 AABB，不得用一个包住全部的巨盒 */];
return root;
```

## 工厂验收

工厂必须返回 `Object3D`，至少包含分类要求的独立 Mesh、材质槽、锚点和局部碰撞。严禁在工厂中使用 `window`、`document`、网络、动态脚本或第二份 Three.js。MCP 会拒绝缺少几何、部件关键词、材质参数或预览图的提交。

## 预览规则

素材预览器会依据实际包围盒自动取景。若模型仍出现零件分离，优先检查 helper 的坐标轴和圆柱旋转，再检查各部件是否重复平移；不要用缩放掩盖装配错误。预览主体应占据主要画面，背景只用于观察轮廓和反光。
