# 素材目录说明

素材按类别拆分，原场景资产总表见 `素材/公共/原场景清单.json`，来源文件校验值见 `素材/公共/原始文件校验.json`。目前拆分包含 36 个道具、48 个命名材质、57 类 Web Audio 合成声音，以及仓库/码头/堆场/围场、港口背景、地面天气、PAC-9、第一人称双手、无人机、机械犬、HUD 和特效。

| 目录 | 内容 |
|---|---|
| `素材/原有场景/道具/` | 原场景构造器生成的 36 个独立道具入口 |
| `素材/原有场景/材质/` | 48 个原场景材质的可视样板 |
| `素材/原有场景/场景组合/` | 仓库、码头、堆场、围场入口 |
| `素材/原有场景/港口背景/` | 吊机、轮船、小艇、远景 |
| `素材/原有场景/地面天气/` | 港区地面与天气入口 |
| `素材/原有场景/源码/` | 按场景构造、道具、材质、地面天气分组的源码 |
| `素材/角色/`、`素材/武器/` | 第一人称双手、无人机、机械犬和 PAC-9 |
| `素材/UI/`、`素材/特效/` | HUD 样式/演示、粒子与贴花演示 |
| `素材/音效/` | 57 类程序合成声音的试听和 WAV 导出 |
| `素材/公共/` | 共享原场景运行时、素材预览器、生成脚本与清单 |

早期生成的 `素材/原有场景/原有仓库.html`、`原有20尺集装箱.html` 等是精选入口，不代表完整资产数量。用户原有的 `素材/暖阳旧木-课桌.html` 保持原样，不属于本协议。

## 预览

在项目根目录运行 `py -m http.server 8000 --bind 127.0.0.1`，打开 `http://127.0.0.1:8000/素材/原有场景/` 后浏览分类目录。角色、武器、UI、音效和特效入口在各自目录。使用同源本地 HTTP 可避免浏览器对本地文件 iframe 的限制。

原场景入口需要 `素材/公共/原场景运行时.html`，单独复制入口时必须连同公共目录一起带上。浏览器地图编辑器位于 `编辑器/`，可从协议素材清单加载建筑、道具、地面材质、角色和武器，并支持拖拽放置、变换、空气墙、工程保存和 HTML 导出。首次使用请按 [编辑器方案](编辑器方案.md) 通过本地 HTTP 服务打开。

## AI 素材指南

从 [AI 素材生成指导](AI素材生成指导.md) 进入；其中按道具建筑、材质、地图片段碰撞、人物动作、武器、UI特效、音效语音分类，并提供小模型可直接复制的 HTML 模板和检查清单。

原始 `index.html` 与 `练枪靶场/saltline-original.html` 不修改。`素材/公共/原场景运行时.html` 是供新素材预览的副本。
