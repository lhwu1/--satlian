# 音效与语音生成指南

阅读 [总规则与 HTML 模板](00-总规则与模板.md)，输出一个独立音频素材 HTML。该类别允许用页面内 Web Audio 合成声音，但禁止远程音频、下载音频和额外声音文件。

- 先说明声音用途、时长、音高/音色变化和触发方式。合成参数必须固定、可复现，点击试听后才播放。
- 使用 `AudioContext`/Web Audio 节点合成；不要自动播放、录音、访问麦克风或网络。不能用运行环境外的文件路径。
- 页面提供中文名称、播放/停止和参数说明。若提供 WAV 导出，必须在该 HTML 内由音频样本生成，不能引用外部文件。
- 不要把机械叫声、提示音或合成声描述为真人录音/真实语音。若用户需要可懂的人声台词，需要提供合法本地录音素材；本规范禁止 AI 页面联网拉取声音。
- 元数据 `category` 为“音效”，`assetKind` 为 `audio`。音频无碰撞，`alongColliders=[]`。

原场景有 57 类 Web Audio 程序合成声音，没有录制的人声文件。请区分已有合成音效、用户提供录音和新生成的合成音。
