# 武器开镜（ADS）附属指南

本指南补充 [50-武器.md](50-武器.md) 未覆盖的开镜瞄准规范。开镜（Aim Down Sights, ADS）是 FPS 游戏的核心交互：玩家按下瞄准键时，武器整体前移并上移，使机械瞄具或光学瞄具的中心与摄像机光轴对齐，同时后期着色器对画面进行收紧、模糊和暗角处理。

---

## 一、开镜机制概览

在 `index.html` 原场景中：

1. **player 对象**有 `ads` 属性，取值 `[0, 1]`，表示从腰射（0）到开镜（1）的插值进度。由右键按下/松开触发平滑过渡。
2. **武器模型**提供 `root.userData.alongAnchors` 锚点数据。引擎在玩家开镜时读取锚点，将武器组整体平移，使 `sight`（瞄具中心）对准摄像机光轴。
3. **后期着色器**通过 `uAds` uniform 值：
   - 对画面边缘进行 blur 混合（`uAds * 0.75` 强度）
   - 收紧暗角（`uAds * 0.22` 额外暗角 + `uAds * 0.08` 向内收缩）
   - 准星在 `ads >= 0.6` 时自动隐藏

素材文件只负责提供正确的锚点和几何，**不实现** `ads` 插值或武器移动逻辑。

## 二、alongAnchors 锚点规范

### 必须提供的锚点

| 锚点 | 含义 | 位置要求 |
|------|------|----------|
| `muzzle` | 枪口中心 | 枪管最前端内凹处，枪口面中心。用于射击方向、枪口闪光、弹壳抛射线起点 |
| `sight` | 瞄具中心（视线交汇点） | 机械瞄具的准星/缺口中心，或光学瞄具的镜片中心。**开镜时此点将与摄像机光轴重合** |
| `grip` | 握把握持中心 | 主握把（手枪式握把）被手掌握住的中心点 |

### 可选锚点

| 锚点 | 含义 | 说明 |
|------|------|------|
| `stock` | 枪托抵肩中心 | 枪托尾部与肩窝接触的中心点，用于第一/第三人称姿态调整 |
| `supportGrip` | 前握把/战术握把中心 | 护木下方的辅助握把握持中心 |
| `mag` | 弹匣插入口中心 | 弹匣与机匣连接的接口中心 |

### 坐标约定

- 所有锚点坐标是**武器模型自身的局部坐标**，单位米，右手系（Y 向上，Z 向后）
- 枪口方向沿 **-Z**（与总规则一致）
- `sight[1]`（Y 值）即 `sightY`，是开镜时武器上移量的核心依据
- `sight[2]`（Z 值）影响武器开镜时的前后位移

### 示例（参考 PAC-9 原场景）

```javascript
root.userData.alongAnchors = {
  muzzle:  [0, 0, -0.531],    // 枪口在原点前 0.531m（沿 -Z）
  sight:   [0, 0.069, 0.021],  // 瞄具中心 Y=0.069m, Z=0.021m
  grip:    [0, -0.1, 0.073],  // 握把在原点下方 0.1m
  stock:   [0, 0.03, 0.36],   // 枪托在后方
  supportGrip: [0, -0.04, -0.23]  // 前握把
};
```

## 三、瞄具几何要求

### 机械瞄具（Iron Sights）

适用于不带光学镜片的传统枪械（步枪照门/准星、手枪后瞄具）：

1. **准星（Front Sight）**：位于枪口附近，通常是圆柱形或片状凸起。准星的**顶面中心**即是 `sight` 的参考点。
2. **照门（Rear Sight）**：位于机匣后部，有缺口或觇孔。照门的**缺口底部中心**与准星顶面对齐后即为 `sight` 位置。
3. 两者必须在同一条竖直平面（X=0）上，`sight` 取两者连线的中点或视线交点。

### 光学瞄具（Red Dot / Scope）

适用于带镜片的瞄准镜或红点镜：

1. **镜筒**：圆柱形或方形外壳，固定在皮卡汀尼导轨上。
2. **镜片窗口**：镜筒前端的透明窗口。PAC-9 风格实现中用一个带着色器的半透明平面模拟光学镜片。
3. `sight` 取**镜片窗口中心**。

**镜片窗口的 PAC-9 风格实现（可选，参考原场景）：**

```javascript
// 在 along-factory 内部创建镜片窗口
const sightWindowShape = new THREE.Shape();
sightWindowShape.moveTo(-0.0192, 0.0525);
sightWindowShape.lineTo( 0.0192, 0.0525);
sightWindowShape.lineTo( 0.0192, 0.0788);
sightWindowShape.lineTo( 0.0138, 0.0842);
sightWindowShape.lineTo(-0.0138, 0.0842);
sightWindowShape.lineTo(-0.0192, 0.0788);
const sightGeo = new THREE.ShapeGeometry(sightWindowShape);
// 然后用自定义 ShaderMaterial（参考原场景 Ev 材质）创建发光镜片
// 或用简单的 MeshStandardMaterial({ color: 0xff3020, emissive: 0xff1000 })
```

### 瞄具安装方式

瞄具通过**皮卡汀尼导轨（Picatinny Rail）**安装在机匣顶部。导轨是标准接口，宽度约 0.021m，每隔约 0.005m 一个凹槽。武器模型应在机匣顶部建模导轨。

## 四、视线对齐自检清单

生成武器后，按以下步骤检查开镜可用性：

1. **X=0 对称**：枪管、瞄具、握把的重心应在 X=0 平面上（武器左右对称）。
2. **sightY 合理性**：瞄具中心高度通常在 0.05 ~ 0.09m 范围。过低会导致开镜时武器上移过多、手部遮挡视线；过高则偏离人体工学。
3. **muzzleZ 向前**：枪口 Z 值应比枪身前端更负（沿 -Z），确保射线方向正确。
4. **sight 在机匣上方**：瞄具不应嵌入机匣或护木内，至少高出 0.015m。
5. **无遮挡物**：sight 点到 muzzle 点的连线上不应有其他几何部件穿过（如前握把、导气箍）。
6. **握把夹角**：握把与枪管轴线的夹角约 70°~80°，符合人手握持习惯。

## 六、典型武器 sightY 参考值

| 武器类型 | sightY (m) | 说明 |
|----------|-----------|------|
| 手枪（机械瞄具） | 0.035 ~ 0.05 | 枪管短，瞄具低矮 |
| 步枪（机械瞄具） | 0.060 ~ 0.075 | 导气式，准星在枪管前 |
| 步枪（光学瞄具） | 0.065 ~ 0.085 | 镜筒比机械瞄具略高 |
| 冲锋枪 | 0.055 ~ 0.065 | 枪身紧凑 |
| 霰弹枪 | 0.060 ~ 0.080 | 双枪管/泵动结构 |
| 机枪/轻机枪 | 0.070 ~ 0.090 | 枪身较大，瞄具相应更高 |

注：以上值为武器模型原点（通常在机匣中心）到瞄具中心的 Y 轴距离。不同建模者的原点选择会导致数值偏移，关键是保持自身一致。
