# 人物与动作生成指南

阅读 [总规则与 HTML 模板](00-总规则与模板.md)，每次只生成一个人物 HTML。人物素材必须是完整三维身体，不能用头像、手部或贴图代表整个人。

视觉风格默认写实，并对齐当前港区地图中的工业材质与低饱和配色。用户指定其他风格时必须遵循用户要求；角色与同场景建筑、武器、道具统一风格，不能做成光滑塑料玩具或比例夸张的卡通人。人物元数据必须填写 `visualStyle` 与 `styleReference`。

- 局部原点在双脚中点，Y 向上，角色正面朝 `-Z`。包含头、躯干、双臂、双手、双腿、双脚，前后左右均可见。
- 用命名 `Group` 建立骨架：`hips` → `spine` → `head`；`spine` 下有 `arm_l`、`arm_r`；`hips` 下有 `leg_l`、`leg_r`。每个关节组原点位于关节处。
- 皮肤、衣物、护甲、装备使用不同材质槽。提供局部占位碰撞盒；碰撞盒不是骨骼，也不是命中检测系统。
- 只按请求提供静态姿势。若用户要求动作，在单个 HTML 内提供动作设计说明和可调关节，不要假称预览器已有动画控制器。
- 元数据 `category` 为“角色”，`assetKind` 为 `character`。说明身高和姿态。

原场景只有第一人称双手、无人机、机械犬等内容，没有完整玩家人体，也没有可复用的人体动作骨架。新生成的人体是新增规范素材，不能标注成从原场景提取。

## 人物细节硬门槛

人物必须按人体比例拆分头部/头盔、躯干、战术背心、双臂、双手、双腿、膝部和鞋靴，并按需求加入背包、弹袋、无线电等装备。手、武器握把和扳机位置要匹配，不能使用无装备的低细节胶囊人或单色方块；服装分层、褶皱和护具应通过独立几何或程序纹理表达。
