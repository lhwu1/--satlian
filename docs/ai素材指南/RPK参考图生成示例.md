# RPK 参考图生成示例

这份示例用于把“侧面写实轻机枪”转成可运行的 HTML 素材。它是约束示例，不是固定模型。

## 先读图，再选参数

- 枪口朝左（局部 `-Z`），枪托朝右（`+Z`），机匣位于原点。
- 主体轮廓：冲压机匣、细长圆枪管、带斜面的护木、弧形盒式弹匣、镂空伸缩枪托。
- 设计变量：`receiverProfile="stamped"`、`handguardProfile="vented"`、`stockStyle="skeleton"`、`magazineType="curved_box"`、`sightLayout="rail+post"`。

## 工厂步骤

1. 用六点以上的截面生成机匣，前端和护木以连接面重叠 1–3 mm。
2. 用曲线扫掠枪管，枪口、导气箍和节套共享同一轴线。
3. 用带斜面截面挤压护木，在左右面开通风/M-LOK 槽；槽是切口或凹陷，不是贴在外面的黑色方条。
4. 用五到七个连续截面生成弧形盒式弹匣，顶部加入供弹座卡口和底部底板；参考图没有弹鼓时不得使用圆柱盘。
5. 用上下承力梁和侧板生成枪托，侧板之间保留贯通窗口，尾部用橡胶尾垫闭合。
6. 最后加入导轨齿、机械瞄具、拉机柄、抛壳窗、铆钉和材质磨损。

## 提交前检查

侧视轮廓应先像一把完整枪，再看细节；45° 视角不能出现漂浮件、穿插件或方块替代件。若主体仍像积木，回到截面和曲线阶段修正，不得用增加铆钉或随机噪声掩盖。
