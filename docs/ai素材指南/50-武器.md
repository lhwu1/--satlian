# 武器生成指南

阅读 [总规则与 HTML 模板](00-总规则与模板.md)，输出一个完整武器 HTML。武器是可复用模型素材，不实现射击或伤害逻辑。

- 枪口沿局部 `-Z`，Y 向上。完整展示枪身、枪管、枪口、握把、枪托、瞄具和请求的附件；不能用一块方盒代替。
- 枪身、金属件、聚合物、橡胶等分开材质槽。给出合理尺度和抓握方向。
- 提供 `root.userData.alongAnchors`：`muzzle`、`grip`、`sight` 的局部坐标；需要时加 `stock`、`supportGrip`。
- 给出贴合实体的局部摆件碰撞盒。枪口锚点不是碰撞盒。
- 元数据 `category` 为“武器”，`assetKind` 为 `weapon`。声明当前素材只是模型，不含弹药、后坐力、瞄准或伤害逻辑。

原场景可参考 PAC-9 和第一人称双手。拆分武器与角色时保持各自独立 HTML。
