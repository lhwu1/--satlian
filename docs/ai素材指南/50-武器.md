# 武器生成指南（v2 — 质感版）

阅读 [总规则与 HTML 模板](00-总规则与模板.md) 和 [55-武器开镜附属指南](55-武器开镜附属指南.md)，输出一个完整武器 HTML。武器是可复用模型素材，不实现射击或伤害逻辑。

## 硬性要求

- 枪口沿局部 `-Z`，Y 向上。完整展示枪身、枪管、枪口、握把、枪托、瞄具和请求的附件；不能用一块方盒代替。
- 枪身、金属件、聚合物、橡胶等分开材质槽。给出合理尺度和抓握方向。
- 提供 `root.userData.alongAnchors`：`muzzle`、`grip`、`sight` 的局部坐标；需要时加 `stock`、`supportGrip`。
- 给出贴合实体的局部 AABB 碰撞盒。
- 元数据 `category` 为"武器"，`assetKind` 为 `weapon`。

---

## 质感技术（必用，缺一不可）

原始 PAC-9 的写实感完全来自以下四项技术。**缺少任何一项都会让成品变成塑料玩具**。

### 1. 顶点颜色噪点材质

原始 PAC-9 不是用纯色 MeshStandardMaterial，而是给每个顶点注入微调后的颜色值。这是金属漆层颗粒感、塑料细微色差、摩擦暗斑的全部来源。

在 factory 函数开头声明 hash 工具函数（直接复制，不要改动）：

```javascript
// 伪随机 hash — 从原始 PAC-9 提取，确定性、无副作用
function hash(x, y, z) {
  return Math.sin(x * 12.9898 + y * 78.233 + z * 37.719) * 43758.5453 -
         Math.floor(Math.sin(x * 12.9898 + y * 78.233 + z * 37.719) * 43758.5453);
}
```

然后写一个 `applyMetalNoise` / `applyPolyNoise` / `applyRubberNoise` 函数，或者通用的：

```javascript
// 通用顶点颜色注入 — 从原始 PAC-9 sm() 函数简化而来
// geo: THREE.BufferGeometry（需要有 position）
// baseColor: [r, g, b] 0~1
// wear: 0~1, 金属零件用 0.3~0.6，聚合物/橡胶用 0
// normalTest: 传入 [minZ, maxZ, epsilon] 数组时，启用"朝上表面氧化"效果
//             金属枪管、机匣等水平放置的部件必须启用
function applyVertexNoise(geo, baseColor, wear=0, normalTest=null) {
  const pos = geo.attributes.position;
  const col = new Float32Array(pos.count * 3);
  const normals = geo.attributes.normal;
  for (let i = 0; i < pos.count; i++) {
    const x = pos.getX(i), y = pos.getY(i), z = pos.getZ(i);
    // 0.8~1.0 倍 baseColor 的自然颗粒
    let f = 0.9 + 0.2 * hash(Math.round(x*70), Math.round(y*70), Math.round(z*70));
    // 磨损：金属朝上表面（normal.y 大）额外叠加氧化暗斑
    if (wear > 0 && normals) {
      const ny = Math.abs(normals.getY(i));
      const nz = Math.abs(normals.getZ(i));
      // 只有法线不在极端朝上（>0.95）或极端朝下的才参与
      const middle = ny > 0.15 && ny < 0.95;
      if (middle) {
        const p = hash(Math.round(x*300), Math.round(y*300), Math.round(z*300));
        const d = Math.max(0, p - 0.84) / 0.16;
        f *= 1 + wear * 1.6 * d * d;
      }
    }
    col[i*3]   = baseColor[0] * f;
    col[i*3+1] = baseColor[1] * f;
    col[i*3+2] = baseColor[2] * f;
  }
  geo.setAttribute('color', new T.BufferAttribute(col, 3));
}
```

### 2. Shape + ExtrudeGeometry（带 bevel 倒角）

**绝对禁止**用 BoxGeometry 做枪身主体、护木、握把、弹匣等大部件。必须用 Shape 描述截面轮廓，再用 ExtrudeGeometry 沿深度方向挤压，或用 CatmullRomCurve3 + TubeGeometry 扫掠，**必须开启 bevelEnabled**。截面至少包含斜面、渐缩或孔洞中的一种；bevel 产生的微小圆角是"金属冲压件"的标志。BoxGeometry 只允许用于导轨齿、铆钉、卡扣等二级细节。

不要把本节示例当成唯一外形。先从参考图选择 `receiverProfile`、`handguardProfile`、`stockStyle`、`magazineType` 和 `sightLayout`，再用同一套连接点生成新的形体。AI 可以改变截面点、曲线控制点、护木开孔布局和枪托骨架，只要枪口方向、接口位置、人体工学和连续性检查通过。

```javascript
// 示例一：护木截面（带散热孔凹槽的复杂轮廓）
function makeHandguard(depth=0.16) {
  const s = new T.Shape();
  s.moveTo(-0.019, 0.0);
  s.lineTo( 0.019, 0.0);
  s.lineTo( 0.020, 0.003);
  s.lineTo( 0.020, 0.014);
  s.lineTo( 0.017, 0.017);
  s.lineTo(-0.017, 0.017);
  s.lineTo(-0.020, 0.014);
  s.lineTo(-0.020, 0.003);
  s.lineTo(-0.019, 0.0);
  // 中间挖空（握把安装孔）— 可选
  // const hole = new T.Path();
  // hole.moveTo(-0.006, -0.004); ... s.holes.push(hole);

  const geo = new T.ExtrudeGeometry(s, {
    depth: depth,
    bevelEnabled: true,
    bevelThickness: 0.002,
    bevelSize: 0.002,
    bevelSegments: 1,
    steps: 1,
    curveSegments: 8
  });
  // 让截面朝向武器的前后方向（-Z）
  geo.rotateY(Math.PI / 2);
  // 修正方向：原始截面在 XY 平面，挤压沿 +Z，rotateY 后变成沿 +X，再平移到正确位置
  return geo;
}

// 示例二：盒式弹匣必须按参考图做弧形曲线；圆盘弹鼓只能在参考图明确为弹鼓时使用。
function makeCurvedMagazine(points, width=0.052) {
  const curve = new T.CatmullRomCurve3(points);
  return new T.TubeGeometry(curve, 12, width * 0.42, 8, false);
}
```

**每个部件的 noise 参数参考表**：

| 部件 | baseColor [r,g,b] | wear |
|------|-------------------|------|
| 机匣主体（金属阳极） | [1.0, 1.0, 1.0] 乘以 #3a3a3a | 0.45 |
| 枪管/导气管（蓝化钢） | [0.75, 0.82, 0.92] | 0.6 |
| 护木（聚合物） | [1.0, 1.0, 1.0] 乘以 #1f1f22 | 0 |
| 握把护板（聚合物） | [1.0, 1.0, 1.0] 乘以 #1f1f22 | 0 |
| 枪托垫（橡胶） | [1.0, 1.0, 1.0] 乘以 #262626 | 0 |
| 瞄准镜镜筒（金属深灰） | [1.0, 1.0, 1.0] 乘以 #2a2a2a | 0.3 |

**注意**：先算好 baseColor 的 RGB 值（0~1 范围），比如 `#3a3a3a` = `[0x3a/255, 0x3a/255, 0x3a/255]` = `[0.231, 0.231, 0.231]`。

### 3. 瞄准镜镜片 Shader（光学瞄具）

机械瞄具（准星+照门）不需要 Shader。光学瞄具（红点镜、倍率镜）必须用自定义 ShaderMaterial 生成镜片，否则看起来是塑料片。

以下是从原始 PAC-9 提取的简化版瞄具 Shader，效果够好，直接复制：

```javascript
// sightWindowGeo: THREE.ShapeGeometry 或 THREE.PlaneGeometry 作为镜片窗口
// 镜片要稍微比窗口大一圈（1.004 倍）放在窗口背面（离眼睛远的一侧）
function makeScopeLens(windowGeo) {
  const geo = windowGeo.clone();
  // UV 需要映射到窗口的本地坐标系
  geo.computeBoundingBox();
  const bb = geo.boundingBox;
  // 重写 UV 到 [0,1]
  const uv = geo.attributes.uv;
  const pos = geo.attributes.position;
  for (let i = 0; i < pos.count; i++) {
    uv.setXY(i, (pos.getX(i) - bb.min.x) / (bb.max.x - bb.min.x),
                 (pos.getY(i) - bb.min.y) / (bb.max.y - bb.min.y));
  }

  const mat = new T.ShaderMaterial({
    transparent: true,
    depthWrite: false,
    side: T.DoubleSide,
    fog: false,
    uniforms: {
      uBright: { value: 7 },
      uSun: { value: new T.Vector3(0.5, 0.8, 0.3).normalize() },
      uSunCol: { value: new T.Color(1.0, 0.95, 0.85) },
      uZen: { value: new T.Color(0.55, 0.65, 0.85) },
      uHor: { value: new T.Color(0.85, 0.65, 0.45) },
      uTilt: { value: 0.1 }
    },
    vertexShader: `
      varying vec3 vView, vFwd, vRight, vUp, vWPos, vWN; varying vec2 vUv;
      uniform float uTilt;
      void main(){
        vUv = uv;
        vec4 mv = modelViewMatrix * vec4(position, 1.0); vView = mv.xyz;
        vFwd = (modelViewMatrix * vec4(0.0, 0.0, -1.0, 0.0)).xyz;
        vRight = (modelViewMatrix * vec4(1.0, 0.0, 0.0, 0.0)).xyz;
        vUp = (modelViewMatrix * vec4(0.0, 1.0, 0.0, 0.0)).xyz;
        vWPos = (modelMatrix * vec4(position, 1.0)).xyz;
        vWN = normalize(mat3(modelMatrix) * normalize(vec3(0.0, -uTilt, 1.0)));
        gl_Position = projectionMatrix * mv;
      }`,
    fragmentShader: `
      varying vec3 vView, vFwd, vRight, vUp, vWPos, vWN; varying vec2 vUv;
      uniform float uBright; uniform vec3 uSun, uSunCol, uZen, uHor;
      void main(){
        vec3 d = normalize(vView), fw = normalize(vFwd);
        float k = max(dot(d, fw), 1e-3);
        vec2 a = vec2(dot(d, normalize(vRight)), dot(d, normalize(vUp))) / k;
        float r = length(a), px = max(fwidth(r), 1e-5);
        float dotR = max(0.0011, px * 0.9), ringW = max(0.00045, px * 0.6);
        float dotI = 1.0 - smoothstep(dotR - px, dotR + px, r);
        float ring = 1.0 - smoothstep(ringW - px * 0.5, ringW + px, abs(r - 0.0128));
        float ang = atan(a.y, a.x);
        float tick = (1.0 - smoothstep(0.0, px * 1.2 + 0.0004, min(abs(a.x), abs(a.y))))
                   * step(0.0128, r) * (1.0 - smoothstep(0.0165, 0.0175, r));
        float ret = clamp(dotI + ring * 0.8 + tick * 0.8, 0.0, 1.0);
        ret += 0.05 * exp(-r * r / 0.00002);
        vec3 retCol = vec3(1.0, 0.11, 0.045) * ret * uBright;
        vec3 wv = normalize(vWPos - cameraPosition); vec3 n = normalize(vWN);
        if (dot(n, wv) > 0.0) n = -n;
        vec3 rf = reflect(wv, n);
        float fres = pow(1.0 - abs(dot(wv, n)), 3.0);
        vec3 sky = mix(uHor, uZen, clamp(rf.y * 1.4 + 0.2, 0.0, 1.0));
        float sd = max(dot(rf, uSun), 0.0);
        sky += uSunCol * (pow(sd, 6.0) * 0.6 + pow(sd, 90.0) * 6.0);
        float band = smoothstep(0.25, 0.5, vUv.x * 0.6 + vUv.y) *
                     (1.0 - smoothstep(0.62, 0.95, vUv.x * 0.6 + vUv.y));
        vec3 coat = mix(vec3(0.30, 0.50, 0.95), vec3(1.0, 0.62, 0.28),
                        clamp(fres * 2.2 + vUv.y * 0.75 - 0.15, 0.0, 1.0));
        vec2 e = abs(vUv - 0.5) * 2.0; float edge = smoothstep(0.90, 1.0, max(e.x, e.y));
        float refl = 0.12 + 0.60 * fres + 0.07 * band;
        vec2 eg = (vUv - vec2(0.5, 0.16)) * vec2(1.0, 1.6);
        retCol += vec3(1.0, 0.10, 0.04) * 0.20 * exp(-dot(eg, eg) * 60.0)
                * (1.0 - smoothstep(0.985, 0.9995, k));
        vec3 col = (sky * 1.5 + vec3(0.03, 0.035, 0.045))
                 * coat * refl * (1.0 - edge) + retCol;
        float alpha = clamp(0.20 + 0.32 * fres + 0.05 * band + 0.6 * edge, 0.0, 0.94);
        gl_FragColor = vec4(col, alpha);
      }`
  });
  return new T.Mesh(geo, mat);
}
```

### 4. Canvas 程序生成贴图（可选）

用于枪身品牌标识、序列号、警告标签、瞄具分划板。原始 PAC-9 的 `TC()` 函数生成 1024x512 贴图。如果不写 Canvas 贴图，可以跳过这一步，但**至少前三项（顶点颜色、挤压截面、瞄具 Shader）必须有**。

## 金属部件的"真实感检查"

生成完成后自查：

1. **bevel 倒角是否开启**？任何 BoxGeometry 都要淘汰，至少把机匣、护木、枪托、弹匣换成 Shape+ExtrudeGeometry 版本。
2. **vertexColors: true 是否开启**？所有金属/聚合物/橡胶材质都必须开。
3. **每个 Mesh 是否调用了 applyVertexNoise**？
4. **金属件 wear 值是否合理**？枪管、机匣、导轨、枪机 > 0.4；聚合物和橡胶 = 0。
5. **瞄具镜片用了 ShaderMaterial 吗**？如果用了光学瞄具（红点、倍率镜），必须用第 3 节的 Shader；机械瞄具可以不用。
6. **枪管膛线**：枪管如果是 TubeGeometry + 变半径的，效果更好；退而求其次可以在 CylinderGeometry 表面叠一圈很细的环形 Mesh。
7. **弹匣形制**：先识别参考图。AK/RPK 等盒式弹匣必须是弧形、渐缩并带供弹座卡口；将它做成圆盘弹鼓属于结构错误，必须在提交前拒绝。

## 给模型的生成契约（提交前必须逐项输出）

```js
const weaponSpec = {
  feed: { type: 'curved_box', single: true, mount: 'magwell' },
  axis: { muzzle: '-Z', stock: '+Z', center: [0, 0, 0] },
  parts: [
    { id:'receiver', type:'receiver', parent:null, profile:'stamped', solid:true },
    { id:'handguard', type:'handguard', parent:'receiver', profile:'vented', rail:'continuous' },
    { id:'barrel', type:'barrel', parent:'receiver', mount:'barrelSeat' },
    { id:'magazine', type:'magazine', parent:'magwell', feed:'curved_box', solid:true },
    { id:'grip', type:'grip', parent:'receiver', mount:'gripSeat' },
    { id:'stock', type:'stock', parent:'receiver', style:'skeleton', solid:true }
  ],
  palette: { receiver:'gunmetal', handguard:'polymer_black', grip:'polymer_black', stock:'polymer_black', pad:'rubber' }
};
```

模型必须先输出并自检 `weaponSpec`，再执行工厂。`parts` 中的每个部件都要能在预览中单独选中；如果检查发现两个供弹系统、没有 `magwell`、配件没有 `parent` 或零件没有实体厚度，必须返回具体部件并重新生成。允许改变 `profile`、`style`、槽位数量和材质色阶，只要 `feed`、挂载关系、轴线、锚点和碰撞约束成立。

- 枪口沿 `-Z`，Y 向上。模型原点（0,0,0）放在**机匣中心附近**（大致握把上方、枪管下方的交汇点），方便其他部件的局部坐标计算。
- `alongAnchors` 至少提供 `muzzle`、`sight`、`grip`；建议额外提供 `stock`、`supportGrip`、`mag`。
- `sightY`（`sight[1]`）决定开镜时武器上移量，通常在 0.060~0.090m。
