# UI 与特效生成指南

阅读 [总规则与 HTML 模板](00-总规则与模板.md)，每次只输出一个可复用的 UI 样式或特效演示 HTML。

- UI 使用中文、适配窄屏与宽屏，不依赖远程字体。CSS、SVG、Canvas 和图形均写在同一 HTML 内。
- 受击方向、命中提示、标志、准星等应清楚区分状态，保持可读性和低遮挡。按用户要求提供颜色、大小或动画参数。
- 特效可用 Canvas 或 `ctx.THREE` 几何/粒子表现；必须限制粒子数和生命周期。不要使用计时器或自行创建永久渲染循环；遵循预览运行时提供的调用方式。若运行时没有动画更新接口，只输出静态预览并注明限制。
- UI/标志不需要三维碰撞，写 `alongColliders=[]`。三维特效若有实体部分，按局部坐标提供碰撞。
- 元数据 `category` 分别填写“UI”或“特效”，`assetKind` 使用 `ui` 或 `effect`。

原场景 HUD 样式、命中反馈、标志和粒子代码已按类别拆出。它们不是独立图片文件；图标和形状由页面内 SVG/CSS/Canvas 绘制。
