# 总规则与 HTML 模板

这份规则适用于所有类别。小模型按顺序完成：读本页 → 读一个类别页 → 复制模板 → 只替换要求的内容 → 按检查清单自查。一次只输出一个完整 HTML 文件，不输出整款游戏。

## 不允许的内容

1. 不修改或覆盖原始 `index.html`、`练枪靶场/saltline-original.html` 或用户已有素材。
2. 不使用任何网络资源：禁止 `http://`、`https://`、CDN、Google Fonts、远程字体、远程图片、模型、音频、脚本、CSS `url()`、`fetch`、XHR、WebSocket。
3. 不生成额外图片、模型、音频、JSON 或 JS 文件。几何、材质、图案和音频必须写在同一个 HTML 内。需要采样图案时用程序生成的 Canvas；不得加载图片。
4. 不写读写文件、读取父页面、访问 Cookie/本地存储、摄像头、麦克风、网络或系统接口的代码。禁止 `eval`、`Function`、Worker、计时器和自建渲染循环。
5. 不在素材中伪造编辑器、动画系统、联网、伤害判定等未提供的功能。

## 统一视觉风格（必读）

- 默认风格为**写实风格**，并以沿线现有港区、仓库、集装箱和道具为视觉参照。比例、轮廓、材质粗糙度、金属反光、磨损程度、颜色饱和度和细节密度都要符合真实用途。
- 如果用户指定卡通、低多边形、科幻、二次元或其他风格，则以用户指定为准；不要擅自混入默认写实风格。
- 同一地图、同一套装备或同一次生成任务中的素材必须保持同一种风格。生成新物件前先检查相邻/复用素材的外观，再沿用它们的比例、配色和材质语言；不能出现写实场景配塑料玩具人物等跳脱组合。
- 为每个新素材在元数据中填写 `visualStyle`，取值为明确风格名；`styleReference` 写清参考对象或用户提供的风格要求。缺少风格参考时使用“沿线现有港区资产，写实风格”。
- 不得把“用了 PBR 材质”当成写实完成。结构比例、剪影、分件、表面粗糙度与磨损也要合理；不确定时减少装饰，避免玩具感和夸张高光。

## 坐标和性能

- 使用米为单位，右手坐标系，Y 向上。地面道具的局部原点放在底面中心，角色原点放在双脚中点。
- 几何、材质和碰撞都使用素材自己的局部坐标。不得写场景世界坐标。
- 为实体提供贴合的局部 AABB 碰撞盒；门洞、窗洞等要保留通道，不得用一个大盒子封死。
- 每个可替换部位使用材质槽；相同形状尽量复用几何与材质，避免高面数和大量动态光源。
- Three.js 由预览器作为 `ctx.THREE` 注入。不得再引入第二份引擎。

## 固定 HTML 模板

复制此模板。AI 只替换标题、JSON 元数据和工厂函数。工厂必须返回一个 `THREE.Object3D`。

```html
<!doctype html>
<html lang="zh-CN"><head><meta charset="utf-8">
<meta name="viewport" content="width=device-width,initial-scale=1">
<title>素材名称</title>
<style>html,body{margin:0;width:100%;height:100%;overflow:hidden;background:#15191d;color:#eee;font:14px sans-serif}iframe{width:100%;height:100%;border:0}header{position:fixed;left:12px;top:12px;padding:10px;background:#111c;border-radius:6px}h1,p{margin:0}h1{font-size:16px}p{margin-top:4px}</style></head>
<body><iframe id="preview" title="素材预览"></iframe><header><h1 id="asset-title"></h1><p id="status">正在加载</p></header>
<script id="along-asset" type="application/json">
{"schema":"along.html-asset/1","id":"ai.example_prop","name":"中文名称","version":"1.0.0","category":"道具","assetKind":"prop","origin":"AI生成","units":"m","visualStyle":"realistic","styleReference":"沿线现有港区资产"}
</script>
<script id="along-factory" type="text/plain">
const T=ctx.THREE;
const root=new T.Group();
const mat=new T.MeshStandardMaterial({color:0x806040,roughness:0.85});
const mesh=new T.Mesh(new T.BoxGeometry(1,1,1),mat);
mesh.position.y=0.5;
mesh.userData.alongSlot='body';
mesh.castShadow=true; mesh.receiveShadow=true;
root.add(mesh);
root.userData.alongSlots=[{id:'body',name:'主体'}];
root.userData.alongColliders=[{min:[-0.5,0,-0.5],max:[0.5,1,0.5],surface:'wood'}];
return root;
</script>
<script src="../公共/素材预览.js"></script>
</body></html>
```

工厂内允许使用 `ctx.THREE`、普通局部变量和确定性计算。不要使用 `window`、`document`、网络接口、随机无界循环或外部依赖。目录路径中的相对预览脚本必须按素材最终所在目录修正；若目录层级不同，计算正确相对路径。

## 元数据与接口

`along-asset` 是 JSON，必须有 `schema`、唯一 `id`、中文 `name`、`version`、`category`、`assetKind`、`origin`、`units`、`visualStyle` 和 `styleReference`。ID 形如 `ai.small_crate`，只用小写英文字母、数字和下划线，且不能与已有清单冲突。

`along-factory` 内是函数体，不要另包函数声明。接收注入对象 `ctx`，从 `ctx.THREE` 创建对象，最后 `return root`。网格槽位写在 `mesh.userData.alongSlot`；槽位说明写在 `root.userData.alongSlots`；局部碰撞写在 `root.userData.alongColliders`，形式为 `{min:[x,y,z],max:[x,y,z],surface:'metal'}`。没有实体碰撞的 UI/纯标志可用空数组。

这只是素材文件格式。不能据此宣称地图编辑器已经能扫描、拖放、替换材质或导出地图。
