# 生成后检查清单

每项都检查；遇到不符合就先修复再输出。

1. 只有一个完整 HTML 文件，含 UTF-8、viewport、唯一中文标题。
2. `along-asset` 是可解析 JSON，schema 为 `along.html-asset/1`，ID 唯一且分类正确。
3. `along-factory` 是完整函数体，使用注入的 `ctx.THREE`，返回独立 `Object3D`。
4. 所有网格有默认可见材质；可换材质的网格有槽位，槽位有说明。
5. 几何完整、方向和原点合理；尺寸用米，碰撞盒在局部坐标并覆盖实体、不堵通道。
6. 不存在外链、CDN、`http(s)`、远程字体/图片/模型/音频、`fetch`、XHR、WebSocket、额外文件或绝对路径。
7. 不存在访问父页面、Cookie、本地存储、文件、相机、麦克风、系统接口，不使用 `eval`、`Function`、Worker 或自建永久循环。
8. 对运行效果只报告实际检查过的内容；注明未测试项目和当前运行时缺少的能力。
9. 文件应放在用户指定的素材分类目录；预览器相对路径与该目录层级一致。不要覆盖已有文件。

如能在本地打开页面，检查控制台无错误、模型可见、预览加载完成；如不能运行，不要声称已通过运行测试。
