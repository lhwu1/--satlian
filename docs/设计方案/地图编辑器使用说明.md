# 地图编辑器与 MCP

需要 Node.js 18 或以上。在仓库根目录执行 `npm run editor`，打开 http://127.0.0.1:8765/编辑器/index.html 。编辑器默认空白，没有预设底板或人物。独立地图 `地图/晴日港区集装箱争夺.html` 可直接双击离线查看。

点击“添加可调地基”创建底板，右侧修改宽、厚、长及位置；可添加多个底板并自由调整变换。素材可拖入场景，点击卡片放在原点。拖放按画布坐标粗略定位，精确落点请用右侧位置数值调整。选中建筑、物品或底板后，在对象材质中选择部位和材质，点击“应用材质”。材质卡片也会应用至选中对象，不会创建材质球。缩略图逐项渲染真实工厂，初次加载需要等待。

添加双方出生点后调整位置；点击“封闭地图边界”按所有未旋转底板的包围范围添加四面空气墙。调整底板范围后需重新封闭边界。碰撞显示开关可检查对象和空气墙。空气墙注册为只阻挡玩家的碰撞体；编辑器观察相机可穿越。多个底板之间的空隙、路线可达性及掩体遮挡仍需人工检查。

拖动环绕，滚轮缩放，WASD 平移，空格上升、Ctrl 下降。“自由视角”锁定鼠标，Esc 退出。保存工程保留变换、材质和地图设计信息；打开工程继续修改。导出 HTML 前检查晴天、底板、两队出生点和四面封闭空气墙。工程保存可选择磁盘目录，HTML 导出通过浏览器下载。

## MCP 设置

编辑器顶部“设置 / MCP”有独立配置界面，可编辑、保存、复制标准配置：

```json
{
  "mcpServers": {
    "along-map-editor": {
      "command": "node",
      "args": ["F:/AAAtask/fps/编辑器/mcp-server.cjs"]
    }
  }
}
```

把路径改为本机仓库绝对路径，并将配置粘贴到支持 MCP stdio 的 AI 客户端。网页中保存配置不会自动替客户端安装或启动 MCP。客户端启动后也会提供 8765 本地编辑器服务；如该服务已经运行，MCP 会复用本地事件文件同步结果。设置中的“连接 / 检测”检查同源本地桥；它不是远程 MCP HTTP 接口。

AI 应先调用 `read_guidance` 获取完整分类指导和 `guidanceToken`，再通过 `list_assets` 复用已有素材。`create_asset` 接受包含元数据、工厂、材质槽和碰撞的 HTML，生成实际文件并加入素材清单。`validate_map` 检查地图；`create_map` 验证后写入工程和单文件 HTML。新地图在设置中显示“载入生成地图”按钮，点击后替换场景，请先保存工作。

写入工具强制检查指导凭据、米制变换、晴天、双方出生点、底板和四边空气墙。人物细节、三路绕行、掩体质量和视觉风格属于提供给 AI 的指导，工具无法自动证明这些美术或可达性要求。工厂使用 JavaScript 执行，语法与禁用标识检查不构成安全沙箱，适合本机可信 AI 输出。

## 示例与检查

港区示例经 MCP 工具生成，包含 79 个对象、双方出生点、中央争夺区、吊机、船只、箱阵、海面动画和四面空气墙，天气为晴天。HTML 为自由观察页，尚未接入完整 FPS 对战与出生逻辑。当前人物为直接重做的程序几何模型，已有迷彩、战术背心、弹袋、头盔、耳机、护膝和步枪；与《战术小队》成品写实角色仍有明显差距。汤姆逊 M1928 是可放置和改材质的枪械模型，尚未接入射击控制器。

`npm ci` 安装浏览器测试依赖。`npm test` 测试 MCP 协议和规则；`npm run test:browser` 使用本机 Edge（否则需安装 Playwright Chromium），检查空场景、地基、材质、真实缩略图、MCP 设置、空气墙实际碰撞、HTML 离线导出和模型预览。`npm run build` 重建运行时、素材清单、导出模块与港区 HTML。`node 编辑器/build-assets.cjs` 可重建人物；汤姆逊首次通过 MCP 创建，已有同名文件时保留。
