# 沿线：浏览器地图编辑器

编辑器位于 `编辑器/`，当前使用浏览器制作地图。上方为三维场景和对象属性，下方为素材库；素材可点击放置或拖入场景。建筑、场景组合、道具、地面材质、角色和武器共用 HTML 素材协议，AI 生成的单文件素材也可以导入并立即预览。

## 目录约定

```text
编辑器/                     浏览器编辑器、素材清单生成器
docs/                       编辑器方案和分类 AI 指南
素材/公共/                  共享场景运行时、预览通信与来源清单
素材/原有场景/              原建筑、道具、材质和地面天气
素材/角色/、素材/武器/      可复用人物与武器模型
素材/AI生成/                新生成的 HTML 素材投放目录
地图/                       保存导出的地图 HTML
```

原始 `index.html` 与 `练枪靶场/saltline-original.html` 只作为来源，保持不变。用户原有的 `素材/暖阳旧木-课桌.html` 也不由编辑器覆盖。

## 打开编辑器

从项目根目录运行 `py -m http.server 8000 --bind 127.0.0.1`，然后打开 `http://127.0.0.1:8000/编辑器/`。编辑器可以双击打开静态界面，但浏览器对 `file://` 的本地文件读取有限制，素材预览和地图 HTML 自包含导出要使用本地 HTTP 服务。

素材库清单由 `编辑器/生成素材清单.js` 从素材 HTML 的元数据和工厂脚本生成。素材文件有增删后运行 `node 编辑器/生成素材清单.js` 更新 `编辑器/assets.js`。页面不需要从磁盘动态遍历目录。

## 基本操作

- 点击素材卡片会把对象放在场景中心；拖动卡片到场景可设定大致位置。搜索框和分类按钮用于筛选素材。
- 材质素材以 12 米见方的地板形式放置；“添加地板”会放置更大的混凝土地板。
- 鼠标左键拖动场景空白处旋转视角，滚轮缩放。右侧输入位置、旋转和缩放；选中对象后按 Delete 可删除。
- “显示碰撞体”按素材声明的局部 AABB 显示轮廓。添加空气墙后可独立移动、旋转和缩放。
- “保存工程”下载 `.along-map.json`，用于后续继续编辑；“打开工程”恢复地图对象。
- “导出地图 HTML”将共享三维运行时和对象素材工厂代码写入单个 HTML 页面。导出之后可将页面放入 `地图/`，作为独立地图入口。

## AI 素材导入协议

素材 HTML 必须包含 `#along-asset` JSON 元数据和 `#along-factory` 工厂函数体。固定 schema 为 `along.html-asset/1`；工厂接收 `{THREE, original}`，并返回独立 `THREE.Object3D`。详细格式及禁止项见 [AI素材生成指导](AI素材生成指导.md) 和 `docs/ai素材指南/` 分类文档。不要在素材中加入 Google 字体、远程模型/贴图、CDN、跟踪脚本或网络下载代码。

目前的碰撞显示使用声明的包围盒作为编辑辅助；复杂网格的精确物理碰撞、撤销/重做、材质槽编辑、天气编辑与多人协作可在后续版本扩展。AI 工厂代码会在浏览器中执行，只导入可信来源的素材。

## 预览验证

素材预览与地图编辑器共用 `素材/公共/原场景运行时.html`。父页面与运行时通过 `postMessage` 通信，不直接读取跨源 iframe 内部对象；这让本地预览不再依赖读取 `contentWindow.__ready`。原始场景文件不会被编辑器写入。
