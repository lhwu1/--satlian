## 给小模型的最短指令

请先阅读 `docs/AI素材生成指导.md` 和对应类别指南。严格按总规则生成**一个可离线使用的 HTML 文件**，包含完整几何/绘制内容、内嵌材质、局部碰撞和规定的 `along-asset` / `along-factory` 数据块。禁止外链、CDN、远程字体、图片、模型、音频和额外文件。先按模板生成，再逐项检查清单。不要声称未实现或未测试的功能已经可用。

## 当前素材范围

从原场景拆出的清单见 `素材/公共/原场景清单.json`：36 个道具、48 个命名材质、57 类程序合成声音；另有仓库/集装箱等场景组合、港口背景、地面天气、PAC-9 武器、第一人称双手、无人机和机械犬，以及 UI、特效演示资源。素材目录页和分类入口列出实际文件。原项目没有完整玩家人体模型，也没有录制的人声文件；第一人称手部、机械角色和合成音效不能描述成完整人体或真实语音。

原始 `index.html` 与 `练枪靶场/saltline-original.html` 是只读来源。生成素材只写入新素材文件。地图编辑器、自动扫描、拖拽、碰撞运行验证和自包含地图导出仍是后续功能，不能假定已经实现。
