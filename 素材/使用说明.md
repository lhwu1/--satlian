# 原场景素材预览

在项目根目录运行 `py -m http.server 8000 --bind 127.0.0.1`，然后访问 `http://127.0.0.1:8000/素材/原有场景/` 并选择素材。使用本地 HTTP 服务使素材页与共享运行时同源；直接双击 HTML 的跨文件访问因浏览器设置而异，不作为保证的运行方式。关闭终端可停止服务。

每个素材 HTML 依赖同级的 `公共` 目录。仓库、集装箱、木箱、油桶和标点调用原场景的几何与材质构建器，并提供局部碰撞盒。仓库碰撞和模型供后续编辑器验证，尚未做实际行走碰撞测试。原场景运行时是从原文件生成的共享副本，保留原场景的内容及其可能存在的外链；离线导出和彻底去除这些依赖尚待实现。它不是 AI 生成素材的外链许可。

编辑器、素材自动扫描、拖拽、替换材质和地图导出目前均未实现。已有课桌 HTML 为用户原有文件，不属于上述协议。
