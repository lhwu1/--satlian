地图编辑器使用说明

把下方标记为“可放置”的素材拖入上方场景，或点击卡片放到中心。标记为“仅预览”的 UI、受击效果和音效素材只用于查看，不能放进地图。地图按需要挑选素材，不必把素材库全部堆进场景。

地基：点击“添加可调地基”创建基础平台，选中后可在右侧直接改宽度、厚度和长度（米）。宽度沿 X 轴，长度沿 Z 轴。海面使用独立水面对象，可与地基分别调整。

视角：编辑区拖动旋转、滚轮缩放；点击“自由视角”后用 WASD 平移，空格上升，Ctrl 下降，移动鼠标转向，Esc 退出。

编辑：选中对象后在右侧修改位置、旋转和大小；Delete 删除对象；显示碰撞体可检查素材自带碰撞范围。

导出：导出的 HTML 是独立地图观察页，只显示环境和地图对象，可自由观察场景，不进入对战、不生成玩家或 HUD。拖动旋转、滚轮缩放、WASD 移动，空格上升，Ctrl 下降。

保存工程：首次保存会请求选择一个文件夹，并在其中创建“地图”目录。也可导出独立 HTML 地图。目录扫描要求通过本地 HTTP 服务打开（例如项目根目录运行 py -m http.server 8000）。
